# 預檢 — 外部連結稽核

**外部連結**&#x200B;稽核會檢閱頁面上指向其他網站的連結。 稽核會從您編輯的頁面中檢查每個外部連結，並標示中斷、不安全或無法自動驗證的連結。

## 為何重要

中斷的外部連結是讀取器的死胡同，並向搜尋引擎發出頁面未妥善維護的訊號。 外部連結也是您最無法控制的連結：其他網站可隨時移動、重新命名或移除頁面，而您的連結會自動停止運作。 在發佈前先檢查這些連結，會擷取自從第一次新增以來已過時的連結。

## 稽核檢查的內容

稽核會將問題排序為三個群組：

* **中斷：**&#x200B;每個訪客的連結目前都失敗，預期無法復原。
* **未驗證：**&#x200B;某些訪客的連結失敗、可能僅暫時失敗，或無法檢查。
* **最佳實務：**&#x200B;連結有效，但不應以此方式撰寫，例如不安全的`http://`連結。

稽核會針對出現下列其中一個問題的每個外部連結報告機會：

* **中斷的連結：**&#x200B;任何開啟此連結的人都無法使用此連結。 預檢報告連結在下列情況中中斷：
  * 完全無法連線至其網站，例如網域已不存在。
  * 它會傳回`Status 404`或`Status 410`。
  * 它會傳回`Status 405`，表示網站會拒絕一般頁面要求。
  * 會在回圈中重新導向，或超過20次。 瀏覽器使用相同的限制，並顯示「太多重新導向」錯誤。

  在重新導向後出現其中一個錯誤的連結會以相同方式回報。
* **不安全的連結：**&#x200B;連結使用`http://`，而Preflight未看到它重新導向至`https://`，包括網站未回應時。 開頭為`http://`但重新導向至安全`https://`頁面的連結未標幟。 更新連結以使用`https://`。
* **未驗證的連結：**&#x200B;預檢無法確認連結是否有效，因此會要求您開啟連結，並自行檢查。 機會會說明適用哪個案例：
  * **需要登入：**&#x200B;連結傳回`Status 401`。 沒有帳戶的訪客無法開啟該帳戶，因此請確認這是預期行為。
  * **封鎖自動檢查：**&#x200B;連結傳回`Status 403`或`Status 429`，或網站以其他方式封鎖自動要求，如LinkedIn所做。 確認連結會在瀏覽器中開啟。
  * **社交和登入牆網站：** LinkedIn、Instagram、Facebook、X (Twitter)、TikTok和Threads會傳回對匿名請求具有誤導性的錯誤，因此來自這些網站的`Status 404`、`Status 410`、`Status 405`或重新導向回圈會回報為未驗證而非損毀。
  * **伺服器錯誤：**&#x200B;連結傳回伺服器錯誤(`Status 5xx`)，當預檢再次檢查它時仍然存在。 報告前會重試一次。 錯誤可能是暫時性的，請在發佈前確認連結是否有效。
  * **因法律原因無法使用：**&#x200B;連結會在預檢檢查的地區傳回`Status 451`。 確認其對您的對象有效。
  * **沒有即時回應：**&#x200B;網站沒有即時回應，即使在Preflight重試一次之後。 網站速度可能變慢或暫時停用。

連結可能既不安全又損壞，或者既不安全又未驗證，在這種情況下，兩個機會都會報告。 如果在20個重新導向內達到有效頁面，則不會標幟重新導向鏈結。

## 檢查哪些連結

會檢查頁面上的每個外部連結。 外部連結是指其主機與您正在編輯的頁面不同的任何連結。 主機是網域名稱加上任何非標準連線埠，例如`:8443`。 子網域計為不同的主機，因此`blog.example.com`和`example.com`都是`www.example.com`的外部主機。 相同主機的連結，包括您自己網站的`http://`連結，已改為由[內部連結](./internal-links.md)稽核涵蓋。 網站導覽中的連結一律會包含在內，因為&#x200B;**顯示網站導覽連結**&#x200B;設定僅適用於「內部連結」稽核。 已忽略`mailto:`、`tel:`和`javascript:`等連結。

每個連結會報告一次，即使它出現在頁面上多次或具有不同錨點（例如`#pricing`和`#features`）亦然。 機會會反白顯示連結的第一個位置。

AEM的連結檢查器已標示為無效的連結會納入稽核中，即使編輯器從頁面中移除可點按的連結亦然。 系統會重新檢查連結，而非將其視為信任連結，因此不會報告已開始運作的連結。

## 篩選結果

在詳細資訊頁面上，使用&#x200B;**執行個體**&#x200B;標題旁的篩選條件來僅顯示部分機會：

| 篩選器 | 顯示的機會 |
|---|---|
| **全部** （預設） | 每個機會 |
| **已中斷** | 中斷的連結 |
| **需要驗證** | 未經驗證的連結和不安全的連結 |

如果連結具有多個機會（例如也中斷的不安全連結），每個機會都會顯示在其自己的篩選器下。 如需詳細資訊，請參閱[篩選執行個體](../../audit-results.md#filter-instances)。

## 已知限制

* **私人位址：**&#x200B;私人或內部網路位址的連結（例如內部網路網站）未受到檢查且未回報。
* **時間限制：**&#x200B;每個連結都有自己的時間限制，所以慢速網站不會阻止檢查其他連結。 頁面上的每個連結都會獲得結果。 即使重試一次，仍無法及時回應的連結會回報為&#x200B;**未驗證的連結**，而非損毀。
* **排除的網域：**&#x200B;您網站的設定可以排除特定網域無法檢查。 系統不會檢查及報告排除的網域或其任何子網域的連結。
* **伺服器端檢視：**&#x200B;預檢會從Adobe的伺服器（而非瀏覽器）檢查外部連結。 根據位置、登入或機器人偵測而採取不同行為的網站，可能會傳回與您在瀏覽器中看到的不同結果。 這類連結通常會回報為&#x200B;**未經驗證的連結**，而不是損毀。

## 如何解決

當稽核發現商機時，每個商機都會描述問題和建議的變更，並識別相關的連結。 使用&#x200B;**在頁面**&#x200B;上反白以跳至您內容中的連結，並在新的索引標籤中開啟URL以自行確認問題。 接著，對機會採取行動：

* **中斷的連結：**&#x200B;將連結更新至頁面的新位置，或取代或移除該連結。 若是重新導向回圈，請連絡其他網站的擁有者或連結至其他來源。
* **不安全的連結：**&#x200B;確認安全版本有效後，將連結變更為使用`https://`。
* **未驗證的連結：**&#x200B;請在瀏覽器中開啟連結，並確認它顯示預期的頁面。 如需需要登入的連結，請確認您的讀者應擁有帳戶。 發生伺服器錯誤，請在發佈之前再次檢查連結。 如果連結無法運作，請將其視為已中斷。

若要瞭解如何檢閱和解決商機，請參閱[預檢中的稽核結果](../../audit-results.md)。
